# 系统架构

## 整体架构

```
┌─────────────────────────────────────────────────────────────┐
│                      用户浏览器                             │
│                  (React SPA, Port 3000)                     │
└─────────────────────┬───────────────────────────────────────┘
                      │ HTTP/JSON
                      ▼
┌─────────────────────────────────────────────────────────────┐
│                    Flask 后端 (Port 5000)                    │
│  ┌─────────┐  ┌──────────┐  ┌────────────┐  ┌────────────┐  │
│  │ /health │  │  /chat   │  │  /lyrics   │  │  /music    │  │
│  └─────────┘  └──────────┘  └────────────┘  └────────────┘  │
└─────────────────────┬───────────────────────────────────────┘
                      │ MiniMax API
                      ▼
┌─────────────────────────────────────────────────────────────┐
│                      MiniMax API                            │
│  ┌───────────────┐  ┌─────────────────┐  ┌──────────────┐  │
│  │ 对话模型      │  │ 歌词生成模型     │  │ 歌曲生成模型 │  │
│  │ M2.7-highspeed│  │lyrics_generation│  │  music-2.6   │  │
│  └───────────────┘  └─────────────────┘  └──────────────┘  │
└─────────────────────────────────────────────────────────────┘
```

## 数据流

### 1. 对话理解流程
```
用户输入 → React前端 → POST /api/chat → Flask → MiniMax对话模型 → 返回意图/需求解析
```

### 2. 歌词生成流程
```
用户确认需求 → POST /api/lyrics → Flask → MiniMax歌词模型 → 返回歌词 → React展示 → 用户编辑
```

### 3. 歌曲生成流程
```
用户确认歌词 → POST /api/music → Flask → MiniMax音乐模型 → 返回音频URL → React播放
```

## 技术选型

| 层级 | 技术 | 说明 |
|------|------|------|
| 前端框架 | React 18 | 单页应用 |
| 后端框架 | Flask 3.x | 轻量级 Python Web 框架 |
| AI 服务 | MiniMax API | 对话、歌词、歌曲生成 |
| 状态管理 | React Context | 轻量状态管理 |
| HTTP 客户端 | Fetch API | 前后端通信 |
| 测试 | Playwright | E2E 测试 |

## 模块职责

### 前端模块 (frontend/)
- **App.jsx**: 主应用组件，路由管理
- **components/ChatBox.jsx**: 用户输入，对话交互
- **components/LyricsEditor.jsx**: 歌词展示与编辑
- **components/MusicPlayer.jsx**: 音频播放控制
- **services/api.js**: API 请求封装

### 后端模块 (backend/)
- **app.py**: Flask 应用入口，路由定义
- **routes/**: API 路由模块
  - `chat.py`: 对话理解路由
  - `lyrics.py`: 歌词生成路由
  - `music.py`: 歌曲生成路由
- **services/**: 业务逻辑服务
  - `minimax_service.py`: MiniMax API 调用封装
- **models/**: 数据模型
