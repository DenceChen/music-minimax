# 产品需求文档

## 愿景
让每个人都能轻松创作属于自己的歌曲

## 核心用户故事
1. 作为普通用户，我想通过自然对话创作歌曲
2. 作为音乐爱好者，我想编辑生成的歌词
3. 作为专业用户，我想生成多种风格的音乐

## 功能优先级

### P0 - 必须有
- 对话输入歌曲需求
- AI 生成歌词
- 用户编辑歌词
- AI 生成歌曲
- 在线播放

### P1 - 应该有
- 歌词风格选择（流行/摇滚/民谣等）
- 歌曲时长选择
- 历史记录保存

### P2 - 可以有
- 翻唱功能（上传参考音频）
- 多语言歌词
- 社交分享

## 非功能需求
- 响应时间 < 3秒（对话）
- 歌词生成 < 10秒
- 歌曲生成 < 60秒
