# 用户故事

## 用户故事 1：普通用户创作歌曲
**身份**：普通用户（无音乐背景）
**场景**：看到广告后尝试创作第一首歌
**需求**：用自然语言描述脑海中的歌曲想法

**验收标准**：
- [ ] 用户输入"我想写一首关于夏天的歌"
- [ ] 系统回复理解用户意图
- [ ] 系统生成完整歌词
- [ ] 用户可以播放最终歌曲

---

## 用户故事 2：音乐爱好者编辑歌词
**身份**：音乐爱好者（有一定音乐素养）
**场景**：对AI生成的歌词不满意，想要调整
**需求**：自由编辑歌词后生成歌曲

**验收标准**：
- [ ] 用户看到生成的歌词
- [ ] 用户可以直接修改歌词文本
- [ ] 修改后的歌词用于歌曲生成
- [ ] 最终歌曲反映用户编辑的内容

---

## 用户故事 3：专业用户选择风格
**身份**：独立音乐人
**场景**：为不同项目创作不同风格的音乐
**需求**：指定歌曲风格（流行/摇滚/民谣/嘻哈等）

**验收标准**：
- [ ] 用户可以选择歌曲风格
- [ ] 不同风格生成差异明显的歌曲
- [ ] 风格选择影响歌词和编曲

---

## 用户故事 4：保存历史创作
**身份**：活跃用户
**场景**：之前创作过几首满意的歌，想要回顾
**需求**：查看历史创作记录

**验收标准**：
- [ ] 用户可以看到历史歌曲列表
- [ ] 点击可以回放之前创作的歌曲
- [ ] 可以查看当时的歌词

---

## 用户故事 5：分享创作到社交媒体
**身份**：社交媒体活跃用户
**场景**：创作了一首满意的歌，想要分享
**需求**：一键生成分享链接或直接分享到社交平台

**验收标准**：
- [ ] 用户可以复制分享链接
- [ ] 分享链接可以让他人听到歌曲
- [ ] 支持分享到微信、微博等主流平台
