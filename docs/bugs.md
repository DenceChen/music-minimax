## 已知 Bug

### [BUG-001] 快速点击发送按钮会发送多条消息
- **发现时间**: 2026-05-09
- **严重程度**: P2
- **当前状态**: Open
- **环境**: localhost:3000
- **复现步骤**:
  1. 在输入框输入测试消息
  2. 快速连续点击发送按钮 3 次
  3. 观察发送的消息数量
- **预期行为**: 只有 1 条消息被发送（防抖生效）
- **实际行为**: 3 条消息都被发送出去
- **日志/截图**: 测试截图保存在 test-results/
- **修复方案**: 在 `handleChat` 函数中添加防抖逻辑，例如使用 `useRef` 跟踪上次的点击时间，1 秒内禁止重复提交
